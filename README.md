## Final-Exam Topics

## What is Microprocessor?
A microprocessor is a programmable electronic chip that works as the central processing unit of a computer system. It performs arithmetic, logical, control, and input/output operations by executing instructions.

### What is a Microcontroller?

A microcontroller is a compact integrated circuit that contains a processor, memory, and input/output ports in a single chip. It is commonly used in embedded systems, automation, robotics, and electronic devices.
